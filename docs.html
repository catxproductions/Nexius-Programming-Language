Quick start

Write code in the Studio editor, select Compile to check syntax, then select Run. Ctrl+Enter (or Cmd+Enter) also runs the program.

name = input("What is your name? ")
output("Hello,", name)

Comments

Use ,,, for a single-line comment and matching ... markers for a multiline comment.

,,, This line is ignored

...
This section is ignored.
It can span multiple lines.
...

Variables and values

Assign values with one equals sign. Names begin with a letter or underscore and may contain letters, numbers, and underscores.

player_name = "Alex"
score = 100
is_ready = true
score = score + 5
output(player_name, score, is_ready)

Supported values include numbers, strings, booleans (true and false), and lists.

Input and output

Text input

name = input("Enter your name: ")

Numeric input

score = numinput("Enter a number: ")

Invalid or empty numeric input produces an error. Output accepts multiple comma-separated expressions:

output("Score:", score)
output("Calculation:", 5 + 3)

Values are printed on one line, separated by spaces.

Lists

Comma-separated values inside parentheses create a list. Indexes start at zero.

numbers = (10, 20, 30)
names = ("Alex", "Sam", "Jordan")
output(numbers)
output(numbers[0])
output(names[2])

Use square brackets to read an item. The index must be a whole number within the list's bounds.

Console commands

clear()

Clears the program output console. It does not stop execution.

wait(time)

Pauses execution for the specified number of seconds. The value must be non-negative; decimal seconds are allowed.

output("Starting...")
wait(2)
output("Two seconds later.")
clear()
output("Console cleared.")

Conditions

Begin with if -- condition:. Optional branches use -- ELIF -- condition: and -- ELSE --:. Close the complete conditional with --.

if -- score >= 100:
  output("You win!")
-- ELIF -- score >= 50:
  output("Almost there.")
-- ELSE --:
  output("Keep trying.")
--

Boolean expressions can be combined with or. It is supported in if, while, and boolIf conditions. The right side is evaluated only when the left side is false:

if -- hullCritical == true or waterLevel > criticalWaterLevel:
  output("Emergency mode enabled.")
--

is_emergency = boolIf -- hullCritical == true or waterLevel > criticalWaterLevel --

Boolean expressions can also be assigned using boolIf:

is_ready = boolIf -- score >= 100 --

Loops

A while block repeats while its condition is true. Close the block with --.

counter = 0
while -- counter < 5:
  output(counter)
  counter = counter + 1
--

An instruction limit helps prevent accidental infinite loops.

Keyboard events

Use checkfor("w") inside a condition to read whether a key is currently held. Prefix a statement with perm. to keep its tracking or event listener active until the program ends. Event blocks are written by the programmer and run when the matching key event occurs.

perm.checkfor("w")

perm.on("w")press --:
  output("W was pressed")
--

perm.on("w")release --:
  output("W was released")
--

while -- checkfor("w") == true:
  output("W is currently held")
--

Without perm., on(key)press and on(key)release pause the program at that line until the next matching event occurs. The event block then runs once, and the program continues with the following statement. With perm., the listener is registered and the program continues; its block runs for every matching event until the program ends or is stopped. Key names are case-insensitive; the space bar is "space".

Counted loops

Use Loop --(amount): to run a block a fixed number of times. The amount is evaluated once when the loop starts and must be a non-negative whole number. Close the block with --.

Loop --(5):
  output("This runs five times.")
--

count = 3
Loop --(count):
  output("Repeated:", count)
--

Functions

Define a zero-argument function with define -- name():, close it with --, and call it with its name and parentheses.

define -- greet():
  output("Hello from Nexius!")
--

greet()

Optional modules: Neural

Import an optional module with imp.moduleName. Neural adds network-specific block syntax and functions through imp.neural.

imp.neural

speed = 0.75
trackwalldistance = 0.30
temp = 0.50
gas = 0
brakes = 0
turning = 0

neural.nexiusRacingBot.inputLayer -- (3):
  neural.in1 = speed
  neural.in2 = trackwalldistance
  neural.in3 = temp
--

neural.nexiusRacingBot.hidden -- (2):
  neural.HL1(5)
  neural.HL2(3)
--

neural.nexiusRacingBot.outputLayer -- (3):
  neural.out1 = gas
  neural.out2 = brakes
  neural.out3 = turning
--

neural.assemble(nexiusRacingBot)
gas = neural.getout1(nexiusRacingBot)

This declares a 3-5-3-3 feed-forward network. The counts after inputLayer and outputLayer specify neuron counts; the count after hidden specifies the number of hidden layers. Each HLN(amount) specifies one hidden layer's size. Identifiers are sequential from 1 and local to their layer declaration.

Inputs read the latest linked variable values each time an output is requested. Output bindings are updated with calculated values. The initial runtime uses randomly initialized weights and sigmoid activation.

Neural feedback (experimental)

After requesting one or more outputs, use neural.observe(ModelName) to store the latest inference in a bounded history of up to 128 observations. Then neural.reward(ModelName) reinforces it or neural.correct(ModelName) applies negative feedback. Reward and correction accept an optional strength from greater than 0 to 10; the default is 1. Each inference can receive feedback only once.

gas = neural.getout1(SubmarineAI)
turning = neural.getout2(SubmarineAI)

if -- distFromObstacle == 0:
  neural.correct(SubmarineAI)
-- ELIF -- distFromGoal == 0:
  neural.reward(SubmarineAI, 2)
-- ELSE --:
  neural.observe(SubmarineAI)
--

This is an experimental reward-modulated gradient update, not a complete reinforcement-learning system. It nudges the whole output vector upward for reward and downward for correction; it does not yet assign credit to individual actions, use replay memory, or persist trained weights. Use simulated environments while this learning rule is being developed.

Language rules

  • Assignment uses one equals sign: score = 10.
  • Equality comparisons use two equals signs: score == 10.
  • if, while, and define headers end with a colon.
  • Every opened block must be closed with its own --.
  • Use the exact -- ELIF -- and -- ELSE -- marker forms.
  • Strings support straight single/double quotes and matching typographic curly quotes.
  • Indentation is for readability; block markers determine block boundaries in the current parser.
  • List indexes start at zero.
If an error points to a line, check its punctuation and the block markers around it.

Current limitations

Nexius is under active development. The browser preview parses Nexius into an internal syntax tree and executes it in a JavaScript-based runtime; it does not yet compile native machine code or WebAssembly.

  • User-defined functions currently take no parameters and return no values.
  • General function calls inside expressions are not supported, except checkfor(key).
  • Lists support creation and indexed reads; mutation methods are not implemented.
  • Classes, arbitrary third-party modules, file I/O, and native compilation are not implemented yet. The optional Neural module is the first supported module.
